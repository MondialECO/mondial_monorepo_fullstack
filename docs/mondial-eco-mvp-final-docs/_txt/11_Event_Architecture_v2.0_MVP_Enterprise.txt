11_Event_Architecture_v2.0 (MVP Enterprise Specification)
Executive Summary
Defines the event-driven architecture required for the MVP. This document only includes events that are necessary for the approved MVP scope.
MVP Scope Only
Included:
- User Events
- Creator Events
- Entrepreneur Events
- Investor Events
- Marketplace Events
- Escrow Events
- AI Events
- Notification Events

Excluded:
- Corporate VC Events
- Secondary Market Events
- Crowdfunding Events
- Debt Financing Events
Event Naming Standard
Format:
<Entity><ActionPastTense>

IdeaCreated
FundingRequestPublished
InvestorMatched
EscrowReleased
